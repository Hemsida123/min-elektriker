Plejd

Plejd är den smarta hem-lösning vi arbetar mest med. Vi hjälper till med planering, installation, driftsättning, programmering och utbyggnad – från en enda dimmer till ett komplett system för belysning, värme och solskydd.

Plejd kombinerar traditionell elinstallation med smart styrning på ett sätt som är lätt att förstå för kunden. Elektrikern sköter installationen och systemet konfigureras i Plejd-appen, vilket gör det enkelt att komma igång och bygga vidare senare.

Dimring, tänd/släck, scenarion, scheman, astro-funktioner och rörelsestyrning – samtidigt som vanliga tryckknappar kan användas.

Appstyrning, dag- och nattsänkning och semesterläge för kompatibla värmelösningar. Gateway behövs för vissa fjärrfunktioner.

Samla flera funktioner i ett kommando – exempelvis “Borta”, “Kväll” eller “Släck allt” – från app eller fysisk knapp.

Låt belysning och andra funktioner följa tider eller solens upp- och nedgång utan att du behöver tänka på det.

Med Plejd Gateway kan systemet nås på distans och integreras med andra kompatibla smarta hem-lösningar.

Plejd uppger att över två miljoner användare använder systemet och att mer än tio miljoner enheter är installerade. För oss är den stora styrkan kombinationen av enkel användning, tydlig app och ett sortiment som täcker flera vanliga funktioner i bostäder och mindre fastigheter.

Vi kan installera en enskild funktion eller planera hela systemet från början så att belysning, värme och andra styrningar hänger ihop på ett bra sätt.

Här kan du välja bland våra vanligaste Plejd-installationer. För större system eller kombinationer av flera funktioner kan du använda projektformuläret längre ner på sidan.

Fast pris gäller enligt respektive produkts förutsättningar. Vid större projekt kontrollerar vi omfattning och kompatibilitet före installation.

Beskriv vad du vill styra och vilka Plejd-produkter som redan finns. Bifoga gärna bilder på befintliga strömbrytare, elcentral, termostat eller installation så kan vi snabbare bedöma rätt lösning.

Jag godkänner att Hörnefors Eltjänst AB använder uppgifterna och bilagorna för att hantera min förfrågan.
